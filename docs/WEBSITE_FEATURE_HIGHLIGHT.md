# 行内样式

常用行内格式都能直接在正文里书写、直接在正文里看到效果，不需要额外面板。

正文可以出现 **加粗强调**、_斜体强调_、~~删除线~~、`行内代码` 和<font color="#0d9488">彩色文字</font>，也可以放一个 [外部链接](https://example.com)。

<mark>荧光笔用于标记真正需要再次看到的内容</mark>，而不是改变整段文字的层级：

- <mark>Mermaid 图表复制后仍然清晰</mark>
- Word 导出的标题与列表结构保持完整
- <mark>本地文件不会被迁移到私有格式</mark>

这些样式可以自由组合，例如 **`加粗的行内代码`** 或 ~~_斜体删除线_~~，原始内容依然是标准 Markdown。
